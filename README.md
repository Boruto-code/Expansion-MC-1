# MC-1 扩展包

## 新机制
### 赋予效果
- 中毒：令其获得（效果等级）枚“毒”标记；拥有“毒”标记的角色回合开始时，失去一点体力（若其体力为1，不执行此效果）并移去1枚“毒”标记。

### 合成
- 根据合成表来转化手牌。
- 杀/雷杀 → 闪
- 桃 ←→ 酒
- 闪电 → 雷杀
- 火攻 ←→ 火杀
- 南蛮入侵 ←→ 万箭齐发
- 过河拆桥 ←→ 顺手牵羊
- 桃园结义 ←→ 五谷丰登
- 五谷丰登 + 无懈可击 → 兵粮寸断
- 无中生有 → 任意普通锦囊牌
- 2x 无懈可击 → 任意普通锦囊牌
- 其它1张牌 → 桃
- 其它2张牌 → 无懈可击

### 附魔
- 对本回合下一张【杀】附加效果。
- 雷：改为雷电伤害 ← 弃置1张牌
- 火：改为火焰伤害 ← 弃置1张牌
- 迫：摸两张牌 ← 弃置1张牌
- 刺：弃置目标一张牌 ← 弃置1张牌
- 速：无距离限制
- 迅：不可被响应 ← 弃置2张牌
- 锋：伤害+1 ← 弃置2张牌
- 坚：结算后获得此牌 ← 弃置2张牌
- 重：目标+1 ← 弃置2张牌
- 退：造成伤害后目标翻面 ← 弃置3张牌
